Windows. Linux. Meet Apple Silicon.

UTM uses Apple's Hypervisor framework to run ARM64 operating systems on Apple Silicon at near native speed. Slower emulation covers Intel x86/x64 on Apple Silicon, plus dozens of other processors including: ARM32, MIPS, PPC and RISC-V. Your Mac can now truly run anything.

Emulate classic operating systems.

Not just the latest and greatest. Emulate older systems whether they ran on PowerPC, SPARC or x86.

Virtualize macOS as well.

Run multiple instances of macOS on your Apple Silicon Mac, useful for developers and builders. Requires an Apple Silicon Mac running macOS Monterey or later.

Designed for macOS.

UTM was created for macOS and only for Apple platforms. It looks and feels like a Mac app, with the privacy and security features you expect.

QEMU and Apple Virtualization without the headache.

UTM is built on QEMU, decades-old, free and open source emulation and virtualization software that is widely used and actively maintained. QEMU is powerful but hard to configure; UTM gives you its flexibility without the learning curve. It can also use Apple Virtualization, a native framework for macOS and Linux on Apple Silicon.

Script it.

Create, configure, and control virtual machines from AppleScript or the utmctl command line tool. Perfect for advanced users, automation, and agents. See the scripting reference.

$ utmctl list
UUID        Status   Name
2F5A…9C1E   started  Debian 12
7B10…E4D2   stopped  Windows 11
$ utmctl start "Windows 11"
$ utmctl start "Debian 12" --disposable
$ utmctl ip-address "Debian 12"
$ utmctl snapshot create "Debian 12" --name "Before update"
$ utmctl snapshot list "Debian 12" --json
$ utmctl snapshot restore "Debian 12" --snapshot "Before update"
$ utmctl usb connect "Debian 12" 05AC:12A8
$ utmctl suspend "Windows 11"
$ utmctl stop "Debian 12"
$ osascript -e 'tell application "UTM" to start virtual machine named "Debian 12"'

Questions

What's the difference in the Mac App Store version?

None. UTM is and always will be completely free and open source, and the App Store version has the same features. Its one advantage is automatic updates. Buying it funds development and shows your support.

How do I contribute?

UTM is on GitHub. You can also contribute to the QEMU project.

Can I run games?

UTM supports DirectX 11 and DirectX 12 on Windows 11 as well as Vulkan 1.3 on Linux. Game compatibility is ongoing work and we encourage to try out your games and provide feedback.
